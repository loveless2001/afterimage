# Research library

Source material for expanding AFTERIMAGE. The current collection is [the 7 September 2026 incident sourcebook](incidents/2026-09-07/README.md).

It contains four downloaded primary PDFs, an annotated bibliography, a chronology with source references, and a separate notebook of fictional expansion ideas. The bibliography also links to original reports, conference media, a replay, and a public research data explorer.

Snapshots are dated in Asia/Bangkok; download timestamps in the manifest use UTC. Preserve old snapshots when adding a later collection so that a changing public report does not silently change the basis of a design decision.

This is development reference material. It is not loaded by the game and does not add a runtime dependency. Source publishers retain their rights in downloaded reports; these documents are not game assets or a grant to reuse their illustrations, prose, or branding.
